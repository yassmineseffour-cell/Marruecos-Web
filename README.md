# 🇲🇦 Marruecos Web

Sitio web dedicado a mostrar la cultura y la riqueza de Marruecos a través de diferentes secciones informativas e interactivas.

Este proyecto fue desarrollado como proyecto de desarrollo web, aplicando conocimientos de HTML, CSS y JavaScript.

## Sobre el proyecto

Marruecos Web permite descubrir diferentes aspectos de Marruecos mediante varias secciones:

- Inicio
- Arquitectura
- Gastronomía
- Festivos y tradiciones
- Historia
- Música
- Sobre mí

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Diseño web responsive
- Git
- GitHub

## Estructura del proyecto

Cada sección dispone de sus propios recursos como hojas de estilo, imágenes y archivos JavaScript.

El proyecto está organizado en diferentes carpetas para facilitar el mantenimiento y la organización del código.

## Objetivo

El objetivo de este proyecto es poner en práctica conocimientos de desarrollo Front-end y crear una experiencia visual que permita conocer diferentes aspectos de la cultura marroquí.
